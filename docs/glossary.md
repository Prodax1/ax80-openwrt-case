# Словарь / Glossary

| Термин | Простыми словами / Plain meaning |
| --- | --- |
| BL2 / preloader | Ранняя ступень загрузки: инициализирует память и ищет следующую. Early boot stage; a bad write can prevent network recovery. |
| TF-A / BL31 | Код низкого уровня для ARM и secure monitor; часть цепочки между BL2 и U-Boot. ARM firmware stage. |
| FIP | Контейнер firmware payloads, здесь BL31 и U-Boot/BL33. Не весь флеш и не образ rootfs. |
| U-Boot | Загрузчик, выбирающий и запускающий ядро; меню и env не гарантируют fallback после kernel hang. |
| NAND | Флеш-память с erase blocks, ECC и возможными bad blocks. Flash storage. |
| MTD | Представление разделов флеша в Linux. Его номера меняются вместе с DTS/картой. |
| DTS / DTB | Исходное/скомпилированное описание железа и разделов для ядра или загрузчика. Device tree. |
| PEB / LEB | Физический eraseblock NAND / логический блок UBI после служебных заголовков. Они имеют разный размер. |
| UBI | Слой управления NAND и томами; это не файловая система и не UBIFS. |
| UBIFS / overlay | Файловая система UBI / место изменяемых файлов поверх read-only SquashFS. |
| SquashFS / /rom | Сжатая файловая система образа, только чтение. Read-only base system. |
| initramfs | Временная система в RAM. Не означает автоматически, что NAND read-only или writable. |
| FIT / ITB | Контейнер ядра, DTB, иногда initrd/rootfs и хешей. Hash integrity is not authenticity. |
| sysupgrade | Механизм обычного обновления OpenWrt; `-T` не заменяет проверку вместимости. |
| UART | Последовательный аппаратный доступ к загрузке/консоли. Наличие pads не доказывает испытанное восстановление. |
| TFTP | Передача загрузочного файла по сети; требует работающей ранней цепочки. |
| factory / EEPROM | Индивидуальные заводские данные радио и идентичности устройства; не прошивка общего назначения. |
| OOB / ECC | Служебная область NAND / коррекция ошибок. Чтение MTD без OOB не равно raw physical dump. |
| redundant env / CRC | Две копии настроек U-Boot / проверка целостности. Нужно проверить реальный Kconfig backend, не только два имени. |
| extroot | Перенос writable overlay на внешний накопитель. В итоговой установке выключен. |
| WPS / PBC | Сопряжение Wi-Fi / временное окно по кнопке. Открытое окно не доказывает успешное подключение клиента. |
